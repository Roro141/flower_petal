# UI to revisit later

Not happy with the UI yet. Come back to this after the core features work. Nothing here blocks the milestones.

## Things already known to be rough

- Fonts: everything still uses the system font. The design calls for Special Elite (titles 20, labels 13) and Atkinson Hyperlegible (body 15, buttons Bold 15).
- Main screen: spike layout (me/junie switch, "samples", two tickets stacked in the middle).
- Ticket buttons: shape, proportions, the tear and the tick.
- Cut screen: layout of the mat, sheet, ruler, loupe position, back arrow, undo tape.
- Unfold screen: plain wall background, flower size, button placement.
- Sill and widget: spacing, name labels, sill board (milestone 3 builds the real window scene).
- Star centre is hard to see on yellow petals.

## Done in the first design pass

- Fonts: Indie Flower for names and labels, Atkinson Hyperlegible for body and buttons.
- Main screen: spike controls and "samples" removed; bigger window; "invite" on a strip of masking tape (same as "undo"); grain on the wall.
- Unfold screen: four flower tiles (5–8 petals) pick the petal count.
- Names on the sill bigger (Indie Flower runs small).
- Star centre has an ink edge so it reads on pale petals.

## Done in the second design pass

- Sign-in screen: a little windowsill with three unnamed flowers above the title, instead of a bare title.
- Name screen: your flower in the window, with the name you're typing showing up on the sill as you type.
- Titles bigger (28) so Indie Flower holds its own.
- Small widget: curtains tied back narrower and shorter so they frame the flowers instead of covering them.
- Cut screen: the chosen paper in the fan has a cream border and sits a bit bigger; the four ready-made petal tiles sit slightly crooked, as if stuck down by hand.

# Fonts

All from [Google Fonts](https://fonts.google.com), downloaded from the official `google/fonts` repository. They live in `Shared/Fonts/` and are bundled in both the app and the widget.

| Font | File | Licence |
| --- | --- | --- |
| The Girl Next Door | TheGirlNextDoor.ttf | SIL Open Font License 1.1 |
| Special Elite | SpecialElite-Regular.ttf | Apache License 2.0 |
| Patrick Hand | PatrickHand-Regular.ttf | SIL Open Font License 1.1 |
| Indie Flower | IndieFlower-Regular.ttf | SIL Open Font License 1.1 |
| Covered By Your Grace | CoveredByYourGrace.ttf | SIL Open Font License 1.1 |
| Atkinson Hyperlegible | AtkinsonHyperlegible-Regular.ttf, -Bold.ttf | SIL Open Font License 1.1 |

Both licences allow bundling the fonts in an app. To switch fonts, change `Fonts.handwriting` (names, labels, titles), `Fonts.reading` (body) or `Fonts.buttons` in `Shared/Fonts.swift`.
